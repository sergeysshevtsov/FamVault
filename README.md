# FamVault

**Your Revit families. Organized. Accessible. Reusable.**

FamVault is an open-source Autodesk Revit add-in designed to simplify how you save, organize, and reuse families across projects.

Instead of searching through folders or repeatedly exporting families, FamVault provides a centralized library directly inside Revit.

### Planned Features

- Save selected Revit families to a personal library.
- Browse families grouped by Revit version.
- Load multiple families into the active project.
- Add comments, descriptions, and metadata.
- Manage family revisions and compatibility.
- Keep or replace older versions when upgrading.
- Quickly save families directly from the Revit Ribbon.
- Store families locally, with future support for Google Drive and shared servers.

### Project Status

🚧 Early development — the first release will focus on local family storage and essential library management.

### Technology

C# · .NET · WPF · Autodesk Revit API
